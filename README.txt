CYBERTECH BURKINA — site vitrine HTML/CSS/JavaScript

CONTENU
- index.html : structure et contenu du site
- style.css : design responsive
- script.js : menu mobile, année automatique et formulaire WhatsApp
- assets/logo-cybertech.png : logo fourni
- assets/wendwaoga-david-kabore.png : portrait fourni

OUVRIR LE SITE
1. Décompressez le fichier ZIP.
2. Ouvrez le dossier cybertech_burkina_site.
3. Double-cliquez sur index.html.
Pour un environnement de développement, vous pouvez utiliser l’extension Live Server de Visual Studio Code.

À PERSONNALISER AVANT PUBLICATION
- Vérifier que les deux numéros de téléphone sont toujours corrects.
- Ajouter votre adresse e-mail professionnelle et vos profils sociaux si souhaité.
- Remplacer le bloc de réalisations provisoire par des projets réels.
- Ajouter les mentions légales et une politique de confidentialité adaptées à votre activité.
- Tester le formulaire sur un téléphone disposant de WhatsApp.
- Configurer un nom de domaine et un hébergement HTTPS.

NOTE
Le formulaire n’enregistre pas les données : il prépare un message et ouvre WhatsApp au numéro +226 78 17 92 10.
